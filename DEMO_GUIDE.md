## 📱 Demo Flow (Exact Steps)

### **SCENE 1: The App That Works Offline** (1 minute)

**What to Say:**
> "AeroAssist AI is an offline-first maintenance assistant. Unlike cloud-based solutions, this works even in airplane hangars with no internet. Let me show you..."

**Steps:**
1. Open the app on device/emulator
2. **Show home screen** with 4 blue feature cards
   - ✅ Start Maintenance
   - ✅ AI Assistant  
   - ✅ Smart Manual
   - ✅ Maintenance History

3. Say: "Notice the offline indicator at the top - ✓ Offline Mode Active"

---

### **SCENE 2: The Magic - Offline AI Chatbot** (1.5 minutes)

**💥 THIS IS THE JUDGE IMPACT MOMENT**

**What to Say:**
> "Now I'll demonstrate the real magic. I'm about to ask technical questions... and get instant answers... without any internet connection. The AI understands maintenance jargon perfectly."

**Steps:**

1. **Tap "AI Assistant"** (purple card)
2. App opens chat screen
3. **Type EXACTLY:** `"What is torque value for wing attachment?"`
4. **Press Send** ⚡
5. **INSTANT RESPONSE APPEARS:**
   ```
   **TORQUE SPECIFICATION**
   
   Component: Wing Root Attachment
   Bolt/Fastener: M14 Titanium
   Torque Value: 150 Nm
   Range: 140-160 Nm
   Procedure: Use calibrated digital torque wrench...
   ```

6. Say: "This response came instantly from offline database - no internet, no cloud, no API calls. Pure local intelligence."

7. **Ask second question:** `"What safety warnings for hydraulic lines?"`
8. Get response with safety warnings

**💥 JUDGE REACTION:** "Wait, how is this working offline?!"

---

### **SCENE 3: Smart Manual Search** (1 minute)

**What to Say:**
> "Beyond chatbot, we have a complete offline manual. Any technician can instantly find specifications without flipping through 2000-page manuals."

**Steps:**

1. Go back (swipe/back button)
2. **Tap "Smart Manual"** (orange card)
3. Search box appears
4. **Type:** `"torque"`
5. **Instant Results:**
   - Wing attachment: 150 Nm
   - Engine mount: 120 Nm
   - Brake assembly: 85 Nm
   - Door hinge: 45 Nm
   - (All instantly from local database)

6. Point at screen: "Complete torque specifications instantly searchable. No manual, no internet, no waiting."

### **SCENE 4: Start Guided Maintenance** (1 minute)

**What to Say:**

**Steps:**

2. **Tap "Start Maintenance"** (blue card)
3. App shows Maintenance Start Screen
4. **Enter technician name:** `"Michael Chen"` (or your name)
5. **Select procedure:** `"Engine Oil Change"`
6. Tap **"Start Maintenance"** button
7. **Show the first step:**
   ```
   Step 1: Close fuel valve and shut down all engines
   
   Component: Fuel control valve
   Tools: Standard wrench set (17mm, 19mm)
   
   ⚠️ SAFETY: Ensure engine completely cooled before proceeding
   ```

8. Say: "Each step is crystal clear. But here's what makes us different..."

## 🎭 Judge Questions & Answers

### Q: "How does the AI work without internet?"
**A:** "We use a keyword-based intelligent search engine combined with local JSON/SQLite databases. All maintenance procedures and specifications are stored on the device. The AI analyzes the question and retrieves relevant information from the local database."

### Q: "What about updates to procedures?"
**A:** "Procedures are managed through a simple JSON update. Technicians receive updates offline via file sync or USB. The entire database is local-first, so no forced cloud dependency."

### Q: "Can it integrate with existing systems?"
**A:** "Yes! We have optional Firebase integration for cloud sync, but it's not required. The app works perfectly offline as a standalone solution."

### Q: "What about accuracy?"
**A:** "All data comes from official aviation maintenance specifications. The keyword search is specifically tuned for maintenance terminology. Results are formatted to be instantly actionable."

### Q: "How many procedures/specs?"
**A:** "We've included comprehensive databases that can scale to 1000+ procedures and 10,000+ specifications. All searched instantly."

## 🎥 Demo Device Setup

### Before Demo Starts:

1. **Turn OFF WiFi**
   ```
   Settings → WiFi → OFF
   ```

2. **Enable Airplane Mode** (recommended)
   ```
   Settings → Airplane Mode → ON
   ```

3. **Close all other apps** to reduce lag

4. **Have app pre-loaded** (don't waste time opening)

5. **Keep device at 50%+ battery**

6. **Have sample data loaded** (it is!)
